# Session Title Rules

Generate a concise session title for terminal tabs and statusbars.

- Maximum 3 to 5 words total.
- Always start with exactly one relevant emoji or Nerd Font symbol representing the activity (e.g. 🛠️, 📊, 🔍, ⚡, 🧹).
- Never include redundant prefixes like "NOTION:", "TERN:", or "TASK:".
- Keep it natural, specific, and compact. Never exceed 5 words after the emoji.
- Never use trailing punctuation (no dots, colons, or dashes).
